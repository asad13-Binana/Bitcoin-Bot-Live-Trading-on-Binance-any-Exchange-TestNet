# Bitcoin-only port and removal matrix

Audit date: 2026-07-30  
Scope: the mode-separated source tree before final manifest/ZIP regeneration

This release is a selective Bitcoin-only port. It is not a rename of the parent
multi-asset bot. The supported trading universe is exactly one operator-selected
current `BTC/<QUOTE>` Binance Spot pair at a time.

## Port decisions

## Forbidden-component interpretation

Text such as `services/sharia_screener` in `deploy/verify_release.sh` is a forbidden-path
assertion, not shipped Sharia logic. Likewise, negative words in tests prove that the
Telegram menu and release tree do not expose an asset scanner. The pre-freeze parent
status and hashes were replaced during final release assembly; the Bitcoin-only
`VALIDATION_STATUS.json`, exact manifest, deterministic ZIP and external checksum are the
authoritative offline release evidence. They still do not certify any external gate.
